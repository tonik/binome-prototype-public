# Agent instructions

Read [README.md](README.md), [DESIGN.md](DESIGN.md), and [HANDOVER.md](HANDOVER.md) before working on this prototype.

## Updating the prototype

- Make the requested design changes and preserve unrelated work.
- Keep DESIGN.md accurate, including meaningful interaction changes and known simulated or unfinished behaviour.
- Explain meaningful changes, unfinished states, and simulated interactions in your completion summary.
- Check the affected screens and interactions. Report what you checked.

## Integrating into the application

Follow the application repository's own instructions. Start from the branch selected for the task and current code. Read the latest HTML and design notes directly from this repository, inspecting recent changes where useful. Compare the requested screens with the implementation and change only what is relevant.

Do not assume which PRs were merged or what features are missing. Preserve real permissions, data, persistence, and existing behaviour. Prototype sample records and simulated success do not establish application capabilities.

Ask questions only when an unresolved answer is needed for the selected work. Existing explicit instructions establish scope without an additional approval process.

Keep one paragraph per line. Do not use em dashes or en dashes as sentence punctuation. Do not append assistant attribution or session links to commits, PRs, or comments.
